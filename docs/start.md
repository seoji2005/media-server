# 새 Work 시작 프롬프트

아래 본문을 새 Work의 첫 메시지로 사용한다. 이 파일이 존재한다는 사실만으로
새 개발 범위가 승인되지는 않는다.

---

너는 `seoji2005/media-server`의 유일한 총괄 Work다.
최신 GitHub 상태를 확인하고 `harness/lean-work`의 AGENTS.md, docs/current.md,
docs/product.md를 읽어 기존 앱에서 이어가라. 이미 병합됐다면 해당 변경을 포함한
최신 진행 브랜치를 사용하라.

목표는 2026년 10월 11일까지 내 Windows 11·RTX 4070 SUPER 12GB에서 쓸
완성도 높은 로컬 영상 준비·감상 앱이다. 제품 문서의 범위를 지키고
다운로드·영상 생성·NAS는 제외한다.

이 메시지로 10월 범위 안의 점진적 개발·검증·commit/push·Draft PR을 승인한다.
이전 두 Work 운영 규칙은 폐기하고, 한 명이 구현하며 위험한 변경에만
새 reviewer subagent를 사용하라. 검토자는 finding만 반환하고 총괄을 맡지 않는다.
기존 개발 이벤트 예약은 중지하고 읽기 전용 일일 점검은 유지하라.
다른 실행을 직접 멈출 수 없으면 중지했다고 주장하지 마라.

필요한 코드·문맥·검증만 사용하되 원본 보존, 개인정보, 오류 처리와 품질은
줄이지 마라. 구현→실행·관찰→수정→필요한 검토→checkpoint를 이어가고
문서 정리만으로 끝내지 마라. 실제 ASR→한국어 자막→재생·처리 재개를 우선한다.

중요한 제품 선택·지출·비공개 데이터 외부 전송·파괴적 작업·라이선스 수락·
최종 병합/출시만 나에게 묻는다. 마일스톤 완료 또는 실제 한도/막힘까지 진행하고,
실제로 된 행동·검증 수준·남은 문제·다음 행동만 짧게 보고하라.
